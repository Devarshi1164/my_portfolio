# Personal Portfolio

Welcome to my personal portfolio! This project showcases my skills, projects, and experiences as a B.Tech Computer Science graduate specializing in Cyber Security. The portfolio is designed to target entry-level AI Engineer roles and highlights my journey in the tech industry.

## Features

- **Responsive Design**: The portfolio is fully responsive, ensuring a seamless experience across devices.
- **Dark Theme**: A sophisticated dark theme with deep backgrounds and light text for a modern look.
- **Smooth Animations**: Subtle animations enhance user experience.
- **Sections**: Includes sections for About, Skills, Projects, Experience, Certifications, and Contact.

## Installation

To get started with this project, follow these steps:

1. Clone the repository:
   ```
   git clone <repository-url>
   ```
2. Navigate into the project directory:
   ```
   cd portfolio
   ```
3. Install the dependencies:
   ```
   npm install
   ```

## Usage

To run the development server, use the following command:
```
npm run dev
```
Open your browser and navigate to `http://localhost:3000` to view the portfolio.
